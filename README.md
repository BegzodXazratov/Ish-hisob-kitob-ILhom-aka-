# Kitob do'koni — harajatlar hisob-kitobi

Kunlik harajatlarni yozib borish va kunlik / oylik / istalgan sana oralig'i bo'yicha hisobot olish uchun parolli veb-dastur.

- Frontend: oddiy HTML/CSS/JS (Vercel'da joylashgan)
- Ma'lumotlar: Supabase (`ilhom` sxemasi, tashqaridan yopiq). Barcha amallar faqat parol bilan olingan sessiya tokeni orqali `ilhom_*` RPC funksiyalari bilan bajariladi.
- Parolni dastur ichidagi ⚙︎ (Sozlamalar) orqali o'zgartirish mumkin.
